# 🚀 SkillForge Platform

> Learn Today. Lead Tomorrow.

SkillForge Platform is a modern Learning Management System (LMS) built using **FastAPI**. It is designed to provide industry-oriented technical training, corporate training, AI-powered interview practice, coding assessments, and placement assistance.

---

# 🌟 Features

## Public Website

- Professional Landing Page
- Course Catalog
- Learning Journey
- Student Success Stories
- Upcoming Batches
- Corporate Training
- Contact Page

# 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Create virtual environment

```bash
python -m venv .venv
```

Activate

Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python run.py
```

Application

```
http://127.0.0.1:8000
```
